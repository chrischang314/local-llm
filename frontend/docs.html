OpenAI-compatible

Use your local models from code.

This app exposes a REST API that follows the OpenAI chat completions shape for model listing, streaming responses, and non-streaming responses.

Base URL

Docker compose exposes the backend on port 8001.

OpenAI SDK base URL
http://localhost:8001/v1
FastAPI explorer

Chat Completions

POST /v1/chat/completions

Send messages to an Ollama model and receive an OpenAI-style response.

Request Body

Field Type Required Description
model string Yes Model ID, such as llama3.2:3b.
messages array Yes Array of { role, content } messages.
stream boolean No Return server-sent events when true.
temperature number No Sampling temperature.
max_tokens integer No Maximum generated tokens.

GitHub + Agent Jobs

Code mode in the main workspace uses authenticated same-origin API routes. Live execution stays disabled until the Kubernetes sandbox canaries pass and AGENT_JOBS_ENABLED=true is set. A GitHub OAuth App is configured once from Settings, then each user clicks Sign in with GitHub and authorizes on github.com. The agent tool loop can read, search, write, inspect diffs, and run bounded shell commands in the isolated workspace. Code jobs use an implementation subagent, reviewer subagent, testing agent, and revision subagent, with bounded review/test loops before push or PR creation.

GET /github/status

Returns GitHub OAuth setup, legacy GitHub App setup, and connection state.

POST /github/oauth/config

Saves the service GitHub OAuth Client ID and Client Secret encrypted in SQLite.

POST /github/oauth/start

Creates an OAuth state token and returns the GitHub authorization URL.

POST /github/install/start

Creates an install state token and returns the GitHub App install URL.

POST /github/install/complete

Completes the GitHub App install callback with installation_id and state.

GET /github/repos

Lists repositories visible to the connected GitHub OAuth account or legacy GitHub App installation.

GET /agent/status

Reports whether code execution is enabled and which secret/config values are missing.

POST /agent/jobs

Queues a code job. Jobs require repo_full_name, base_branch, task, model, and optional test_command.

Create job body
{
  "repo_full_name": "owner/repo",
  "base_branch": "main",
  "task": "Fix the failing unit test and update docs.",
  "model": "qwen2.5-coder:7b",
  "test_command": "python -m unittest discover -s tests"
}

    "messages": [

  }'

curl http://localhost:8001/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama3.2:3b",
    "messages": [
      { "role": "user", "content": "What is Docker?" }
    ],
    "stream": true
  }'

Python

OpenAI client
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="not-needed",
)

response = client.chat.completions.create(
    model="llama3.2:3b",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is Docker?"},
    ],
)

print(response.choices[0].message.content)

JavaScript

fetch
const response = await fetch("http://localhost:8001/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "llama3.2:3b",
    messages: [
      { role: "user", content: "What is Docker?" }
    ],
  }),
});

const data = await response.json();
console.log(data.choices[0].message.content);
